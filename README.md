## 미션 제출하는 법

각 주차 폴더의 `제출/` 안에 **내 닉네임 파일**이 미리 만들어져 있어요. 그 파일만 채우면 됩니다.

```
2주차/제출/카일.md   ← 내 파일만 열어서 채우기
```

```bash
git pull        # 최신 내용 받기
# N주차/제출/내닉네임.md 채우기
git add . && git commit -m "2주차 미션 제출 - 카일" && git push
```

클로드 코드에 이렇게 말해도 돼요 — `"나 카일이야. 2주차 미션 제출 파일 채워줘. 글 링크는 이거야: ..."` → `"커밋하고 푸시해줘"`

푸시하면 [제출 현황](제출현황.md)이 자동으로 갱신돼요. **다른 사람 파일은 건드리지 마세요.**

## 티로 기록 남기는 법

유닛 모임이 끝나면 그 주 폴더의 `README.md` 에 티로 녹화본 링크와 요약을 채워주세요.
클로드 코드에 이렇게 말해도 돼요 — `"3주차 유닛 모임 티로 링크 이거야: {링크}. 요약해서 3주차에 정리해줘"`

## 폴더 구조

```
4th-blog-conversion/
├─ README.md          ← 지금 이 파일
├─ 제출현황.md         ← 자동 생성 (직접 고치지 마세요)
├─ _운영/
│  ├─ 명단.csv         ← 유닛 명단 (유닛장만 수정)
│  └─ 제출현황.py      ← 제출 현황 집계 스크립트
└─ N주차/
   ├─ README.md       ← 그 주 티로 녹화본 · 요약 · 미션
   └─ 제출/
      ├─ _양식.md     ← 제출 양식
      └─ 닉네임.md     ← 내 제출 파일
```

이미지는 글을 쓰는 `.md` 파일과 **같은 폴더**에 넣고 `![](파일이름.png)` 으로 불러오면 됩니다.
