## 올리는 법

과제 올릴 때랑 똑같아요.

```bash
git pull        # 최신 내용 받기
# 파일 작성
git add . && git commit -m "작업 내용" && git push
```

클로드 코드에 이렇게 말해도 됩니다 — `"방금 쓴 거 커밋하고 푸시해줘"`

## 폴더 구조

```
4th-blog-conversion/
├─ README.md        ← 지금 이 파일
└─ N주차/
   ├─ README.md     ← 그 주 티로 녹화본 · 요약 · 미션
   └─ (그 주 자료 · 이미지)
```

이미지는 글을 쓰는 `.md` 파일과 **같은 폴더**에 넣고 `![](파일이름.png)` 으로 불러오면 됩니다.
