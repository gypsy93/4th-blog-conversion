## 📝 요약

**6주 로드맵**

| 주차 | 미션 |
|---|---|
| 1주차 | 블로그 세팅 + 직접 쓴 글 3개 발행 (AI 없이 내 말투 담긴 글 필수) · 통과 시 쉘 2개 |
| 2주차 | 어필리에이트(제휴 마케팅) 배우고 적용 · 통과 시 쉘 2개 |
| 3주차 | 블로그 글로 수익·성과 가설 세우기 |
| 4~6주차 | 가설을 반복해서 갱신하며 조회수 키우기 |

- 미션을 통과하지 못하면 다음 주 참여 자격이 없어지는 **서바이벌 방식**
- 자동화가 갖춰지면 **1일 1글** 권장 (키노 블로그: 1일 1글로 일 방문자 200명대 회복)
- 처음 2주는 AI와 **티키타카(반복 수정·훈육)** 가 제일 많이 필요한 시기. 이걸 거쳐야 자동화가 매끄러워져요.

**네이버 블로그 세팅 가이드**

- **계정**: 오래된 네이버 아이디가 있으면 새로 만들지 말고 살리기. 예전 글은 지우지 말고 비공개 + 별도 카테고리로 이동
- **블로그 아이디**: 특수기호·하이픈 없이 단순한 단어. 변경 기회가 1번뿐이니 신중하게
- **블로그명**: 정체성·전문 분야가 바로 보이게 (예: "두피의 모든 것", "과학적으로 분석하는 피부")
- **별명**: 영문 아이디 그대로 쓰지 말고 하는 일과 연관된 한글 키워드로
- **스킨**: 수평선·베이지 계열의 심플한 디자인
- **기본 서체**: 나눔스퀘어·고딕 같은 각진 서체 (손글씨체 ❌)
- **글씨 크기**: 15~19pt (11~12pt ❌, 24pt 이상은 과함)
- **카테고리**: 4개 안팎 · **앨범형(정방형)** · 페이지당 글 1개
- **퍼스널콘**: 설정 권장 (댓글 달 때 관리되는 블로그 인상)

**글쓰기 · 발행 팁**

- 에디터를 **모바일 화면 모드**로 바꿔서 쓰기 · 줄바꿈은 짧게
- 즉시 발행 대신 **예약 발행**. 발행 후 약 2시간 뒤에 노출되니까
  - 오전 6:30 예약 → 8:30 출근길 노출
  - 오후 4:30 이후 예약 → 퇴근길 노출
  - 내 독자 패턴에 맞게 시간대는 테스트
- 네이버는 에디터 체류 시간이 길수록 사람이 쓴 글로 봐요. AI 자동 발행보다 **직접 예약 설정** 권장

**AI 브라우저 도구: 에고라이트 vs 어사이드**

| 구분 | 에고라이트 | 어사이드 |
|---|---|---|
| 작동 범위 | 브라우저 안에서만 | 로컬 컴퓨터 전체 접근 |
| 지시 방식 | 클로드에서 명령 → 실행 | 채팅창에서 바로 지시 |
| 로그인 | 세션마다 스페이스 생성 | 한 번 로그인하면 계속 자율 작업 |
| 자율도 | 낮음 | 높음 (결제·블로그 수정까지 자동) |
| 초보자 | ✅ 권장 | 주의 필요 |

어사이드는 편하지만 컴퓨터 전체 접근·자동 결제 가능성이 있어서 초보자는 주의. 다음 모임에서 이어서 설명 예정.

**케이 블로그 운영 근황**

- 오래된 아이디로 리빙 블로그를 새로 열어 10/6부터 글 작성
- 20일 안에 AI 작성 글로 **네이버 AI 브리핑 인용**이 0 → 유의미한 수준으로. '백김치 담그는 방법' 글이 AI 브리핑 첫 번째 결과로 노출
- 네이버 **브랜드 커넥트** 체험단 자동 신청 99건 중 1건 선정
- 전략: "수제 버거가 아니라 **맥도날드**" — AI가 찍어내기 쉬운 표준화된 글쓰기
