## 1. 깃허브로 미션 제출하기

이번 주부터 미션은 **깃허브 저장소에 파일로** 내요. 누가 냈는지 [제출 현황](../제출현황.md)에 자동으로 모여요.

### 내 파일 찾기

```
4th-blog-conversion/
└─ 2주차/
   └─ 제출/
      ├─ _양식.md      ← 건드리지 않기
      └─ 내닉네임.md    ← 여기만 채우기
```

모든 크루의 파일이 미리 만들어져 있어요. **내 닉네임 파일만** 열어서 채우세요.

### 제출 3단계

**① 최신 내용 받기**

```bash
git pull
```

처음이면 먼저 받아 와요.

```bash
git clone https://github.com/selfishclub/4th-blog-conversion.git
```

**② 내 파일 채우기**

- `- 항목:` 은 `:` 뒤에 값을 써요. **항목 이름은 바꾸지 마세요** (자동 집계가 이름으로 읽어요)
- 체크박스는 `[ ]` → `[x]`
- 글 링크는 주소 전체를 넣어요: `https://blog.naver.com/아이디/글번호`

**③ 올리기**

```bash
git add . && git commit -m "2주차 미션 제출 - 내닉네임" && git push
```

### 클로드 코드에 맡기기

저장소 폴더에서 `claude` 를 켜고 이렇게 말하면 돼요.

> 나 ○○야. 2주차 미션 제출 파일 채워줘. 글 링크는 이거야: …

> 커밋하고 푸시해줘

### 제출됐는지 확인

푸시하고 1~2분 뒤 [제출현황.md](../제출현황.md) 에서 내 이름을 찾아요.

| 표시 | 뜻 |
|---|---|
| ✅ | 제출 요건 충족 |
| 🟡 | 작성 중 — 빈 칸이 뭔지 같이 보여줘요 |
| ⬜ | 미제출 |

통과와 쉘 지급은 유닛장이 확인하고 따로 기록해요.

### 자주 막히는 곳

- **`git push` 가 거절돼요** → `git pull` 먼저 하고 다시 `git push`
- **다른 사람 파일을 고쳤어요** → 커밋 전이면 클로드에게 "다른 사람 파일 변경 되돌려줘"
- **🟡 에서 안 바뀌어요** → 항목 이름을 바꿨거나, 링크에 `https://` 가 빠졌는지 확인

## 2. 어필리에이트 기초 — 세시간전

### 어필리에이트가 뭔가요

내 글에 **제휴 링크**를 넣고, 독자가 그 링크로 구매·예약하면 **판매 금액의 일부를 수수료로** 받는 구조예요.

```
내 글 → 독자가 제휴 링크 클릭 → 예약·구매 → 나에게 수수료
```

광고(애드포스트)는 클릭당 몇 원이지만, 어필리에이트는 **결제 금액 기준**이라 여행처럼 단가가 큰 분야에서 효율이 좋아요.

### 왜 세시간전인가요

여행 제휴 프로그램 여러 개를 **한 곳에서** 링크 발급·클릭·주문 확인까지 할 수 있어요. 케이의 블로그 자동화도 세시간전 기준이에요.

| 항목 | 내용 |
|---|---|
| 제휴처 | 마이리얼트립 · 클룩 · 아고다 · 트립닷컴 · KKday · 호텔스컴바인 · 부킹닷컴 등 |
| 수수료 | 제휴처마다 다름 (최대 10% 안팎) |
| 가입 조건 | 블로그 · 인스타 · 유튜브 중 1개 이상 등록, 승인 약 1일 |
| 정산 | 익월 25일 · 최소 출금 5만 원 |

> 수수료율·정산 조건은 바뀔 수 있어요. 가입할 때 세시간전 화면에서 꼭 다시 확인하세요.

### 첫 제휴 링크 달기

1. [세시간전](https://3hoursahead.com) 가입 → 내 네이버 블로그 주소 등록 → 승인 기다리기 (약 1일)
2. 쓰려는 글과 맞는 상품 고르기 (호텔·투어·입장권·유심 등)
3. 세시간전에서 그 상품의 **제휴 링크 발급**
4. 글 본문에 링크 넣기 + **수수료 고지 문구** 넣기 (아래)
5. 발행 후 세시간전에서 클릭·주문 들어오는지 확인

> 여행 블로그가 아니어도 괜찮아요. "출장 갈 때 챙기는 것", "부모님 모시고 가기 좋은 근교 호텔"처럼 **내 분야와 여행이 만나는 지점**을 찾아보세요.

### ⚠️ 수수료 고지 — 필수

제휴 링크가 들어간 글은 **돈을 받는 글이라는 걸 독자에게 알려야** 해요. 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」에 따른 의무예요.

**이렇게 쓰세요**

- 위치: 글 **맨 처음** (또는 맨 끝) — 본문과 구분되게
- 모양: 본문보다 **글자를 크게 하거나 색을 다르게**
- 문구: 명확하게

```
이 글은 세시간전 제휴 링크를 포함하고 있으며,
링크를 통해 예약·구매 시 일정 수수료를 받습니다.
```

**이렇게 쓰면 안 돼요**

- ❌ "소정의 수수료를 지급받을 수 있음" 같은 애매한 표현
- ❌ '더보기'를 눌러야 보이게 숨기기, 댓글에만 쓰기
- ❌ 본문 중간에 작은 글씨로 묻기

> 자동화할 때는 클로드에게 규칙으로 박아 두세요 — "제휴 링크가 들어간 글은 맨 위에 수수료 고지 문구를 굵게 넣는다." `CLAUDE.md` 에 저장하면 매번 지켜요.

## 3. AI 브라우저 — 어사이드 vs 에고라이트

### AI 브라우저가 뭔가요

**AI가 직접 조작하는 브라우저**예요. 클로드가 네이버 에디터를 열고, 원고를 붙여 넣고, 세시간전에서 링크를 찾아오는 일을 사람 대신 해요.

- 내가 로그인해 둔 사이트(네이버·세시간전)를 **그 로그인 상태 그대로** AI가 써요
- 사람이 쓰는 창과 **AI가 일하는 창이 따로** 떠요
- **발행 버튼은 사람이 직접** 눌러요 (네이버는 에디터에 오래 머문 글을 사람 글로 봐요)

### 어사이드 vs 에고라이트

| | 에고라이트 (ego lite) | 어사이드 (Aside) |
|---|---|---|
| OS | **맥** | **윈도우 · 맥** |
| 일 시키는 법 | 클로드 코드에서 명령 → 에고라이트가 실행 | 어사이드 채팅창에서 바로 지시 · 클로드 코드와도 연결 가능 |
| 작동 범위 | 브라우저 안에서만 | 로컬 컴퓨터까지 접근 가능 |
| 로그인 | 작업마다 별도 공간(Space) 생성 | 한 번 로그인하면 계속 자율 작업 |
| 자율도 | 낮음 — 시킨 것만 | 높음 — 결제·블로그 수정까지 스스로 |
| 가격 | 무료 | 무료 플랜 (월 크레딧 한도 있음) |
| 초보자 | ✅ 권장 | ⚠️ 주의 |

**어떤 걸 쓸까요**

- **맥** → 에고라이트
- **윈도우** → 어사이드

> ⚠️ **어사이드 주의**: 자율도가 높아서 결제나 글 수정까지 스스로 할 수 있어요. 카드 정보가 저장된 사이트는 조심하고, 일 시킬 때 "발행·결제는 하지 마"라고 꼭 말해 두세요.

### 설치 — 맥 · 에고라이트

1. [lite.ego.app/ko](https://lite.ego.app/ko) 에서 다운로드 → 설치
2. 처음 켤 때 크롬의 북마크·비밀번호·로그인을 한 번에 가져올 수 있어요
3. 설치 과정에서 **ego-browser 스킬이 클로드 코드에 자동으로 들어와요** (따로 깔 것 없음)
4. 에고라이트 안에서 **네이버에 로그인**해 두기
5. 클로드 코드에서 테스트

> /ego-browser 네이버 블로그 글쓰기 창 열어줘

**걸리는 곳**: AI가 일하는 창을 사람이 만지면 AI가 멈추고 물어봐요. 작업 중엔 그 창을 건드리지 마세요.

### 설치 — 윈도우 · 어사이드

1. [aside.com/download](https://aside.com/download) 에서 다운로드 → 실행 파일 열고 설치
2. 어사이드 안에서 **네이버에 로그인**해 두기
3. 클로드 코드와 연결 (PowerShell에서 순서대로)
   - 어사이드 개발자 안내의 **윈도우 설치 명령**으로 `aside` 명령어 설치
   - `aside login --email "내 이메일"` → 어사이드 앱 **설정 › 계정 › 기기**에서 코드 승인 → "Signed in as…" 뜰 때까지 기다리기
   - `claude mcp add aside -- aside mcp`
4. 클로드 코드를 **껐다 다시 켜고** 테스트

> 어사이드로 네이버 블로그 글쓰기 창 열어줘

**걸리는 곳**

- `aside` 명령어를 못 찾는다고 나오면 → **PowerShell 창을 새로 열기**
- 무료 플랜은 매달 크레딧 한도가 있어서 긴 작업은 중간에 끊길 수 있어요
- 회사 보안 때문에 설치가 안 되면 → 클로드가 쓴 원고를 **직접 복사해서 붙여 넣는 반자동**으로 가도 괜찮아요

### 설치 끝나면 — 첫 글 흐름

1. 글 쓸 폴더에서 `claude` 켜기
2. 주제 말하기 → 클로드가 초안 작성
3. "AI 브라우저로 네이버 에디터 열고 붙여 넣어줘"
4. **내가 읽고 고치고** → 예약 발행은 직접

> 처음 2주는 AI와 **티키타카**가 제일 많이 필요한 시기예요. 마음에 안 드는 부분은 "이건 이렇게 고쳐, 앞으로도 그렇게 해"라고 말하고 `CLAUDE.md` 에 규칙으로 쌓아 두세요. 이게 쌓여야 자동화가 매끄러워져요.
