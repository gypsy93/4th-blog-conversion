```bash

```

**② 내 파일 채우기**

**③ 올리기**


통과와 쉘 지급은 유닛장이 확인하고 따로 기록해요.

## 2. 어필리에이트 — 세시간전으로 첫 링크 달기

### 어필리에이트가 뭔가요

**내 글의 링크로 생긴 매출의 일부를 받는 구조**예요.

```
내 글 → 독자가 제휴 링크 클릭 → 제휴처에서 구매·예약 → 결제 금액 일부가 나에게
```

광고를 붙이는 게 아니라, **써 본 것을 추천하고 그 대가를 받는 것**이에요.

### 세시간전 조건

| 항목 | 내용 |
|---|---|
| 수수료 | 최대 10% 안팎 — 제휴처와 상품마다 달라요 |
| 정산 | 익월 25일 — 이번 달 수익은 다음 달 25일에 |
| 최소 출금 | 5만 원 |
| 가입 | 케이 키트를 깔았다면 자동 가입. 안 되면 추천인 링크 [3ha.in/r/346560](https://3ha.in/r/346560) · 코드 `N1AI9A` |

> 출처: 세시간전 블로그 2024.12 기준. 조건은 바뀌었을 수 있으니 가입할 때 다시 확인하세요.

### 첫 링크 달기 5단계

1. **가입** — 세션에서 같이
2. **상품 고르기** — 내가 다녀왔거나 쓸 수 있는 것
3. **링크 만들기** — 내 전용 제휴 링크 복사
4. **글에 넣기** — 본문에 자연스럽게
5. **맨 위에 고지** — 수수료 고지를 글 첫 부분에

> 상품은 **내 경험과 이어지는 것**부터 골라요. 그래야 글이 광고처럼 읽히지 않아요.

### ⚠️ 수수료 고지 — 필수

공정위 「추천·보증 등에 관한 표시·광고 심사지침」과 경제적 이해관계 표시 안내서(2025.12 개정) 기준이에요.

| | |
|---|---|
| **위치** | 제목 또는 **글 첫 부분**. 끝에만 두면 인정되지 않아요 (맨 위에 넣고 끝에 한 번 더는 OK) |
| **하지 말 것** | '더보기' 안, 본문 중간, 댓글, 작은 글씨에 숨기기 · 'AD', 'Sponsor', '파트너스'만 쓰기 |
| **쓸 표현** | '수수료 지급', '판매수익의 일부 지급'처럼 **무엇을 받는지 한국어로** |

**예시**

```
이 글에는 세시간전 제휴 링크가 들어 있어요.
링크로 예약하시면 저는 판매수익의 일부를 수수료로 받습니다.
```

> 자동화할 때는 클로드에게 규칙으로 박아 두세요 — "제휴 링크가 들어간 글은 맨 위에 수수료 고지 문구를 넣는다." `CLAUDE.md` 에 저장하면 매번 지켜요.

## 3. AI 브라우저 — 어사이드 vs 에고라이트

### AI 브라우저가 뭔가요

**로그인된 내 브라우저에서 AI가 클릭과 입력을 대신**해요.

- **읽기** — 검색 결과, 경쟁 글, 대시보드 숫자를 표로 정리
- **조작** — 클릭, 입력, 에디터에 초안 넣기, 임시저장
- **로그인 유지** — 따로 연동하지 않아도 네이버, 세시간전에 로그인된 채로 일해요

> 검색으로 끝나는 일엔 쓰지 않고, **로그인과 클릭이 필요한 일**에 써요.

### 어사이드는 브라우저에게, 에고라이트는 내 AI에게 시켜요

| | 어사이드 (Aside) | 에고라이트 (Ego Lite) |
|---|---|---|
| 한 줄 | AI가 들어 있는 브라우저 | 내 AI가 빌려 쓰는 브라우저 |
| 누구에게 시키나 | 브라우저 안 채팅창에 말로 | 클로드 코드 같은 내 에이전트가 `/ego-browser` 로 |
| 대표 기능 | 메모리, 루틴(정기 실행), 비밀번호 관리, 실행 전 승인 | Space(내 탭과 에이전트 탭 분리), 여러 작업 동시 실행 |
| 잘 맞는 사람 | 클로드 코드가 아직 낯선 분 | 깃허브 제출로 클로드 코드를 쓰는 분 |
| 비용 | 다운로드 무료 · ChatGPT/Claude 구독이나 API 키 연결 | 무료 · 토큰은 쓰는 에이전트 쪽에서 |
| OS | 맥(macOS 15 이상) · 윈도우 | 맥 · 윈도우 |

### 설치 — 어사이드

[aside.com/download](https://aside.com/download)

1. 맥은 `.dmg` 를 Applications 로, 윈도우는 `.exe` 실행
2. 쓰던 브라우저 프로필 연결 (여러 개 연결 가능)
3. ChatGPT나 Claude 구독으로 로그인, 또는 API 키 연결
4. 네이버에 로그인해 두기

개발자 기능: [aside.com/blog/developers](https://aside.com/blog/developers)

### 설치 — 에고라이트

[lite.ego.app/document](https://lite.ego.app/document)

1. 설치 후 Chrome 데이터를 가져올지 물으면 승인
2. 클로드 코드 스킬 목록에 `ego-browser` 가 있는지 확인
3. 클로드 코드에 `/ego-browser` 입력 후 할 일 설명
4. 네이버에 로그인해 두기

깃허브: [github.com/citrolabs/ego-lite](https://github.com/citrolabs/ego-lite)

### 블로그 유닛에서 쓰는 법

**어사이드 · 채팅으로 바로**

- 경쟁 글 분석 — "네이버에서 '[키워드]' 상위 10개 글의 제목, 소제목, 사진 수를 표로"
- 말투 메모리 — "내 블로그 글 3개를 읽고 말투 규칙을 메모리에 저장해줘"
- 루틴 — 매일 아침 내 키워드 순위, 세시간전 클릭 수 기록

**에고라이트 · 클로드 코드와 함께**

- 임시저장까지 — 클로드 코드가 초안을 쓰고 네이버 에디터에 임시저장
- 미션 제출 — 이번 주 글 링크 3개를 모아 깃허브 파일 채우고 push
- 고지 점검 — 내 글 3개 맨 위에 수수료 고지가 있는지 확인

> 1주차에 직접 쓴 글 3개가 여기서 **AI가 배울 내 말투**가 돼요.

### 주의점 — 발행 버튼과 비밀번호는 끝까지 내가

- **발행은 직접** — 자동 발행은 플랫폼 약관에 걸릴 수 있어요. 임시저장까지만 맡기세요
- **비밀번호는 프롬프트에 쓰지 않기** — 로그인과 인증번호는 브라우저에서 직접
- **필요한 계정만** — 에고라이트는 쿠키가 공유돼요. 필요한 사이트만 로그인한 전용 프로필 추천
- **아직 초기 제품** — 버그가 있을 수 있어요. 막히면 채널에 공유해 주세요
